# 1.介绍

对于duckdb来说，内存的管理和维护由不同的模块负责

- buffer pool：对内存进行管理，统计使用量和Eviction 策略
- Buffer Manager：维护实际的内存，并对外提供可供读写的内存块



## Block相关的类

`BlockHandle` 类： **管理block的io操作**，block分为`PersistentBlock`(已经持久化的表数据) 和`TempBlock`（内存block），通过block_id来进行区分。

```c++
class BlockHandle : public enable_shared_from_this<BlockHandle> {
private:
	atomic<BlockState> state;				//block状态，unload说明内存，load说明磁盘
	atomic<int32_t> readers;				//当前block reader数目
	const block_id_t block_id;				//block id
	unique_ptr<FileBuffer> buffer;			// 实际数据缓冲区指针
	atomic<idx_t> eviction_seq_num;			//淘汰序列号（用于优先级排序）
	atomic<int64_t> lru_timestamp_msec;		//LRU时间戳（基于时间的淘汰）
	atomic<DestroyBufferUpon> destroy_buffer_upon;	//// 卸载时的销毁策略
	atomic<idx_t> memory_usage;				//当前内存使用量
	BufferPoolReservation memory_charge;	//从缓冲池预留的内存
	const char *unswizzled;					//Swizzling状态指示器
	atomic<idx_t> eviction_queue_idx;		//在淘汰队列中的索引
};
```

`BlockManager `类：**用于管理`BlockHandle`**, 由于Block 分为Persistent和temp，因此`BlockManager`也分为**`SingleFileBlockManager`**和**`InMemoryBlockManager`**, 二者均继承自`BlockManager` 。前者给有指定文件的，后者是不带文件。

```c++
class BlockManager {
    BufferManager &buffer_manager;//

	unique_ptr<MetadataManager> metadata_manager;//元数据管理器
	optional_idx block_alloc_size;	//分配block的大小，可配
	optional_idx block_header_size;	//block header的大小
}
```

# 2. buffer-pool

设计了3中共8条无锁淘汰队列

![image.png](http://mysql.taobao.org/monthly/pic/202509/2025-09-15-huaxiong-img/bp.png)

- 队列 1 用于缓存普通的 BLOCK（BLOCK_AND_EXTERNAL_FILE_QUEUE，后文简称 BEFQ），这类 BLOCK 在没有被访问的情况下对应的内存块可以直接被释放。
- 队列 2 ～ 7 用于管理运行过程中产生的脏 BLOCK（MANAGED_BUFFER_QUEUE， 后文简称 MBQ），这类 BLOCK 对应的内存在释放前必须要进行持久化。
- 队列 8 用于单独管理小于 256KB 的小内存块（TINY_BUFFER_QUEUE，后文简称 TBQ）。



# 3. 启动时内存模块

`duckdb`启动后，会调用`SingleFileStorageManager::LoadDatabase()` 先加载数据库，同时会启动缓存管理。

```c++
void SingleFileStorageManager::LoadDatabase(StorageOptions storage_options) {
    ...
 
    // 如果文件不存在，则需要创建一个database
    if (!read_only && !fs.FileExists(path)) {
        ...
        // 设置blocksize 大小
        if (storage_options.block_alloc_size.IsValid()) {
            // Use the option provided by the user.
            Storage::VerifyBlockAllocSize(storage_options.block_alloc_size.GetIndex());
            options.block_alloc_size = storage_options.block_alloc_size;
        } else {
            // No explicit option provided: use the default option.
            options.block_alloc_size = config.options.default_block_alloc_size;
        }
 
        //初始化blockmanager
        auto sf_block_manager = make_uniq<SingleFileBlockManager>(db, path, options);
        sf_block_manager->CreateNewDatabase();
        block_manager = std::move(sf_block_manager);
        table_io_manager = make_uniq<SingleFileTableIOManager>(*block_manager, row_group_size); 
    } else {
        //文件存在，则加载同时初始化blockmanager
        auto sf_block_manager = make_uniq<SingleFileBlockManager>(db, path, options);
        sf_block_manager->LoadExistingDatabase();
        block_manager = std::move(sf_block_manager);
        table_io_manager = make_uniq<SingleFileTableIOManager>(*block_manager, row_group_size);
 
        if (storage_options.block_alloc_size.IsValid()) {
            // user-provided block alloc size
            idx_t block_alloc_size = storage_options.block_alloc_size.GetIndex();
            if (block_alloc_size != block_manager->GetBlockAllocSize()) {
                throw InvalidInputException(
                    "block size parameter does not match the file's block size, got %llu, expected %llu",
                    storage_options.block_alloc_size.GetIndex(), block_manager->GetBlockAllocSize());
            }
        }
 
        // load the db from storage
        auto checkpoint_reader = SingleFileCheckpointReader(*this);
        checkpoint_reader.LoadFromStorage();
 
        // check if the WAL file exists
        auto wal_path = GetWALPath();
        auto handle = fs.OpenFile(wal_path, FileFlags::FILE_FLAGS_READ | FileFlags::FILE_FLAGS_NULL_IF_NOT_EXISTS);
        if (handle) {
            // replay the WAL
            if (WriteAheadLog::Replay(db, std::move(handle))) {
                fs.RemoveFile(wal_path);
            }
        }
    }
 
    load_complete = true;
}
```

## **Header**

- Header 目前有 3 个，包括 1 个`MainHeader`和 2 个 `DatabaseHeader`，每个固定大小为 4KB。
- `MainHeader`保存了 `magic_bytes`、`version_number` 和 `flag 列表`，主要用来做一些版本校验，对总体逻辑没什么影响，暂且可以忽略。
- `DatabaseHeader`的核心是保存了 `meta_block`的 id，后续会从这个 `meta_block`开始读取整个实例的元数据（表结构等）。



## Block

Block 固定长度为 256KB（`DEFAULT_BLOCK_ALLOC_SIZE` ），分为metablock 和 datablock。其中block_header 占8字节,记录block_id.

### MetaBlock

MetaBlockPointer: 精确定位到某个元数据块内的某个位置

MetadataBlock:        一个物理块被分割成 **64个** 小的元数据块

```c++
//可以定位到物理块中的某个 4KB 小块，以及该小块内的字节偏移
struct MetaBlockPointer {
    idx_t block_pointer;		//64位，包换block_id 和index；高56位=block_id(物理块id)，低8位=index（64块位置）
	uint32_t offset;			//块内偏移
}

//获取block_id。提取block_pointer的低56位
block_id_t MetaBlockPointer::GetBlockId() const {
	return block_id_t(block_pointer & ~(idx_t(0xFF) << 56ULL));
}
//获取block的索引。提取高8位
uint32_t MetaBlockPointer::GetBlockIndex() const {
    return block_pointer >> 56ULL;
}
```

#### **分配流程**

```c++
MetadataHandle MetadataManager::AllocateHandle() {
    // 1. 查找有空闲小块的物理块
    for (auto &kv : blocks) {
        if (!kv.second.free_blocks.empty()) {
            // 找到了空闲块
            free_block = kv.first;
            break;
        }
    }
    
    // 2. 如果没有空闲块，分配新的物理块
    if (free_block == INVALID_BLOCK) {
        free_block = AllocateNewBlock();
    }
    
    // 3. 从空闲列表中取出一个小块索引
    pointer.index = block.free_blocks.back();
    block.free_blocks.pop_back();
    
    // 4. 标记为脏，返回句柄
    block.dirty = true;
    return Pin(pointer);
}


//4.2 新块分配
block_id_t MetadataManager::AllocateNewBlock() {
    // 1. 获取新的 block_id
    auto new_block_id = GetNextBlockId();
    
    // 2. 创建 MetadataBlock
    MetadataBlock new_block;
    new_block.block = buffer_manager.Allocate(...);
    new_block.block_id = new_block_id;
    
    // 3. 初始化所有 64 个小块为空闲
    for (idx_t i = 0; i < METADATA_BLOCK_COUNT; i++) {
        new_block.free_blocks.push_back(METADATA_BLOCK_COUNT - i - 1);
    }
    
    // 4. 零初始化整个块
    memset(handle.Ptr(), 0, block_manager.GetBlockSize());
    
    // 5. 添加到管理表
    blocks[new_block_id] = std::move(new_block);
    return new_block_id;
}
```

#### 读取元数据

```c++
class MetadataReader : public ReadStream {
private:
    MetadataManager &manager;
    MetadataHandle block;                          // 当前块
    MetaBlockPointer next_pointer;                 // 下一块指针
    bool has_next_block;                           // 是否有下一块
    idx_t offset;                                  // 当前偏移
    idx_t capacity;                                // 块容量
};

void MetadataReader::ReadData(data_ptr_t buffer, idx_t read_size) {
    while (offset + read_size > capacity) {
        // 1. 当前块数据不足，先读取当前块剩余部分
        idx_t to_read = capacity - offset;
        memcpy(buffer, Ptr(), to_read);
        
        // 2. 移动到下一个块
        ReadNextBlock();
        
        // 3. 更新缓冲区
        buffer += to_read;
        read_size -= to_read;
    }
    
    // 4. 读取剩余数据
    memcpy(buffer, Ptr(), read_size);
    offset += read_size;
}
```

#### 写入元数据

```c++
class MetadataWriter : public WriteStream {
private:
    MetadataManager &manager;
    MetadataHandle block;                              // 当前块
    MetadataPointer current_pointer;                   // 当前位置
    optional_ptr<vector<MetaBlockPointer>> written_pointers;  // 已写指针列表
    idx_t capacity;                                    // 块容量（4KB）
    idx_t offset;                                      // 当前偏移
};

void MetadataWriter::WriteData(const_data_ptr_t buffer, idx_t write_size) {
    while (offset + write_size > capacity) {
        // 1. 当前块空间不足，先写满当前块
        idx_t copy_amount = capacity - offset;
        memcpy(Ptr(), buffer, copy_amount);
        
        // 2. 移动到下一个块
        NextBlock();
        
        // 3. 更新缓冲区指针
        buffer += copy_amount;
        write_size -= copy_amount;
    }
    
    // 4. 写入剩余数据
    memcpy(Ptr(), buffer, write_size);
    offset += write_size;
}
```
