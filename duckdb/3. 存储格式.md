- 一个表被分割成多个 `RowGroup`

- 每个 `RowGroup` 最多存储 `122880` 行 (默认)

## MVCC 实现:

\- 更新不直接修改原数据，而是创建 `UpdateSegment`

\- `UpdateSegment` 存储版本链: `(transaction_id, row_id, old_value, new_value)`

\- 读取时根据事务可见性规则选择正确版本

## 并行扫描流程

```c++
bool RowGroupCollection::NextParallelScan(
    ClientContext &context,
    ParallelCollectionScanState &state,
    CollectionScanState &scan_state
) {
    AssignSharedPointer(scan_state.row_groups, state.row_groups);
    
    while (true) {
        idx_t vector_index;
        idx_t max_row;
        optional_ptr<RowGroupCollection> collection;
        optional_ptr<SegmentNode<RowGroup>> row_group;
        
        {
            // 原子地获取下一个扫描单元
            lock_guard<mutex> l(state.lock);
            
            if (!state.current_row_group) {
                // 没有更多数据
                break;
            }
            
            auto &current_row_group = state.current_row_group->GetNode();
            if (current_row_group.count == 0) {
                break;
            }
            
            auto row_start = state.current_row_group->GetRowStart();
            collection = state.collection;
            row_group = state.current_row_group;
            
            if (ClientConfig::GetConfig(context).verify_parallelism) {
                // 测试模式：每个线程扫描 2048 行
                vector_index = state.vector_index;
                max_row = row_start + MinValue<idx_t>(
                    current_row_group.count,
                    STANDARD_VECTOR_SIZE * state.vector_index + STANDARD_VECTOR_SIZE
                );
                
                state.vector_index++;
                if (state.vector_index * STANDARD_VECTOR_SIZE >= current_row_group.count) {
                    // 当前行组扫描完毕，切换到下一个
                    state.current_row_group = state.GetNextRowGroup(*state.row_groups, *row_group).get();
                    state.vector_index = 0;
                }
            } else {
                // 生产模式：每个线程扫描整个行组
                state.processed_rows += current_row_group.count;
                vector_index = 0;
                max_row = row_start + current_row_group.count;
                state.current_row_group = state.GetNextRowGroup(*state.row_groups, *row_group).get();
            }
            
            max_row = MinValue<idx_t>(max_row, state.max_row);
            scan_state.batch_index = ++state.batch_index;
        }
        
        D_ASSERT(collection);
        D_ASSERT(row_group);
        
        // 初始化该行组的扫描
        bool need_to_scan = InitializeScanInRowGroup(
            context, scan_state, *collection, *row_group, vector_index, max_row
        );
        
        if (!need_to_scan) {
            // 跳过该行组 (例如被过滤器排除)
            continue;
        }
        
        return true;
    }
    
    lock_guard<mutex> l(state.lock);
    scan_state.batch_index = state.batch_index;
    return false;
}
```

## Fetch 行数据（**按 RowID 获取**）

```c++
void RowGroupCollection::Fetch(
    TransactionData transaction,
    DataChunk &result,
    const vector<StorageIndex> &column_ids,
    const Vector &row_identifiers,
    idx_t fetch_count,
    ColumnFetchState &state
) {
    auto row_ids = FlatVector::GetData<row_t>(row_identifiers);
    idx_t count = 0;
    auto row_groups = GetRowGroups();
    
    for (idx_t i = 0; i < fetch_count; i++) {
        auto row_id = row_ids[i];
        optional_ptr<SegmentNode<RowGroup>> row_group;
        
        {
            // 1. 定位行组
            idx_t segment_index;
            auto l = row_groups->Lock();
            
            if (!row_groups->TryGetSegmentIndex(l, row_id, segment_index)) {
                // 并行追加场景下可能找不到行
                continue;
            }
            
            row_group = row_groups->GetSegmentByIndex(l, segment_index);
        }
        
        // 2. 检查可见性
        auto &current_row_group = row_group->GetNode();
        auto offset_in_row_group = row_id - row_group->GetRowStart();
        
        if (!current_row_group.Fetch(transaction, offset_in_row_group)) {
            // 该行对当前事务不可见
            continue;
        }
        
        // 3. 获取行数据
        state.row_group = row_group;
        current_row_group.FetchRow(
            transaction, state, column_ids, 
            offset_in_row_group, result, count
        );
        count++;
    }
    
    result.SetCardinality(count);
}
```

**段类型**:

1. ***\*TRANSIENT\****: 内存中的临时段，用于追加
2. ***\*PERSISTENT\****: 磁盘上的持久段，经过压缩

**段大小**: 默认 262144字节  (256KB)

**段统计信息**:如果 min(age)=10, max(age)=40。CheckZonemap 返回 FILTER_ALWAYS_FALSE，跳过整个段

**更新段**：主要用于MVCC
