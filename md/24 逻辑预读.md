# 全表扫描



| 特性         | `btr_cur_open_at_index_side` | `btr_cur_search_to_nth_level` |
| ------------ | ---------------------------- | ----------------------------- |
| **定位方式** | 定位到索引边界（最左/最右）  | 根据search tuple精确定位      |
| **参数**     | `from_left` (bool)           | `tuple` (搜索键)              |
| **使用场景** | MIN/MAX、边界、全表扫描      | WHERE条件查询、点查询         |
| **性能**     | 固定路径，无比较开销         | 需要在每层进行键比较          |

1. **先找到数据的边界**

```c++
|-->ha_innobase::index_first()
|	|-->row_search_mvcc()
|	|	|-->btr_pcur_t::open_at_side()
|	|	|	|-->btr_cur_open_at_index_side() //找到page的边界
|	|	|	|	|-->buf_page_get_gen() //读取page
```

2. 然后不断的移动会去读下一个rec，如果游标已经位于page的最后了，则读取下一个page，否则在当前page中读取

```c++

|	|-->row_search_mvcc()
|	|	|-->pcur->move_to_next(&mtr)
|	|	|	|-->is_after_last_on_page() //判断pcursor是否是page的最后
|	|	|	|-->move_to_next_on_page() //在当前page中读取
|	|	|	|-->btr_pcur_t::move_to_next_page() //读取下一个page

-----------------------------------------------------------------
|	|	|	|-->is_after_last_in_tree()//btree最后位置，则返回
 
```

# 三 cursor 游标

## `3.1 page_cur_t`: 页面级游标

```c++
struct page_cur_t {
    const dict_index_t *index;  // 所在索引
    rec_t              *rec;    // 当前指向的记录指针
    ulint              *offsets;// 记录各字段偏移量
    buf_block_t        *block;  // 当前 buffer 块
};
```

仅表示"当前在某个页面上指向哪条记录"，提供页内移动：**`page_cur_move_to_next` , `page_cur_move_to_prev`**



## 3.2 `btr_cur_t`:  B树游标

```c++
struct btr_cur_t {
    dict_index_t *index;       // 所属索引
    page_cur_t    page_cur;    // 内嵌页面游标（核心位置信息）
    btr_cur_method flag;       // 查找方式（AHI命中/二分搜索等）
    ulint up_match, low_match; // 向上/向下匹配的字段数（用于插入、唯一检查）
    ulint tree_height;         // 悲观操作时记录树高
    uint64_t hash_value;       // AHI 查找时使用的哈希值
    btr_path_t *path_arr;      // 路径数组，用于行数估算
    rtr_info_t *rtr_info;      // R-tree 扩展信息
    ...
};
```

**职责**：

- 封装一次从根到叶的 B+树查找
- 支持悲观/乐观插入、更新、删除操作
- 记录查找路径上的匹配度，用于插入位置和唯一性判断
- **生命周期绑定 mtr**（mini-transaction），mtr 提交后游标失效



## 3.3 `btr_pcur_t`: 持久化游标

```c++
struct btr_pcur_t {
    btr_cur_t      m_btr_cur;          // 内嵌 B 树游标
    ulint          m_latch_mode;       // 当前 latch 模式
    pcur_pos_t     m_pos_state;        // 定位状态（已定位/曾定位/未定位）
    btr_pcur_pos_t m_rel_pos;          // 相对位置（ON/BEFORE/AFTER）
    rec_t         *m_old_rec;          // 存储的旧记录（用于恢复）
    byte          *m_old_rec_buf;      // 存储旧记录的动态缓冲区
    uint64_t       m_modify_clock;     // 存储时的页修改时钟
    page_cur_mode_t m_search_mode;     // 查找模式
    ...
};
```

**职责**：

- 在 mtr 提交后**保存游标位置**（`store_position`），并在下次操作时**恢复**（`restore_position`）
- 支持跨越多个 mtr 的持续遍历（SQL SELECT 扫描全表/范围查询）
- 提供  `move_to_next`,`move_to_prev` 跨页移动
- 主要用于 SQL 层的 SELECT、UPDATE、DELETE
