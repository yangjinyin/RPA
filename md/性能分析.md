# 常用命令：

- **pidstat [option] [interval] [count]: 进程粒度的监控工具**

  ```shell
  -p ALL|pid 所有进程 或者指定pid
  -u cpu相关数据
  -r 内存相关数据
  -w 进程切换相关 cswch(自愿上下文切换) nvcswch(非自愿切换)
  -d io相关统计
  -t 显示出线程相关信息
  ```

- **vmstat:内存相关信息**

  ```shell
  si 每秒从磁盘读入虚拟内存的大小
  so 每秒虚拟内存写入磁盘的大小 si和so如果>0标识物理内存不够用
  bi 每秒写入io设备的块数量
  bo 每秒io设备读出的块数量 bi和bo
  ```

-   **lsof(list open file): 文件相关信息**

  ```shell
  lsof file 显示打开文件的进程
  lsof -c 程序名 显示程序打开了哪些文件
  lsof -p pid 显示进程打开了哪些文件(可以用来查看进程文件位置)
  lsof -i :22 查看22端口被那个程序占用
  lsof -d 10 显示使用fd为10的进程
  ```

- **strace: 跟踪进程的系统调用**

  ```shell
  跟踪进程的系统调用, 并把结果输出到文件out.log里
  输出内容：系统调用的参数、返回值、耗时
  不用-p参数，可以直接跟command运行程序
  ```

- **gcore: 生成一个core 且当前进程不退出**

- **gstack/pstack：输出当前进程的堆栈**

- **ftrace: 用来跟踪内核函数、事件，堆栈等内容**

  ```shell
  1.函数跟踪（Function Tracing）
  //启用 ftrace 函数跟踪：
  echo function > /sys/kernel/debug/tracing/current_tracer
  2. 性能分析（Latency Tracing）
  ftrace 还可以用于分析内核操作的延迟，比如分析进程调度的延迟、IO 延迟等。通过启用相应的延迟跟踪，可以帮助调试实时系统和高性能系统的瓶颈。
  ```
